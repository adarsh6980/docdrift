DocDrift demo

DocDrift finds doc code snippets that no longer match the code, proposes fixes, and re-runs each fix. Only fixes that pass the re-run are shown as verified.

Scope: 3 synthetic seeded fixture repos, 5 snippets executed. Fixtures exist to demonstrate the pipeline end to end; scores on them are not a measure of real-world performance. A real open-source-repo benchmark is separate future work.

Live run. Model calls went through Nebius Token Factory (model nvidia/Nemotron-3_5-Lightning); token usage below is measured.

Record note: This page is rendered from a reconstructed record of the live run: the run's raw report was not retained in full, so every value shown comes from the run's surviving artifacts (recorded output, rendered page and public fixture code). The rejected fix's code and its rerun error are not in the record, which is why the stale_unfixed row shows no fix evidence.
